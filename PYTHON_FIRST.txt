Tiger.M.M - Python 说明（正常情况你**不用**看这个文件）
========================================================

本程序自己要跑在 Python 上。

  ★ 你通常不用做任何事 —— 第一次双击 Tiger.M.M.bat 时，它会**自己**去下载官方
    Python 安装包、核对（SHA256 + Python 官方数字签名，两样都核）、然后静默装好
    （只装给你自己用，不弹管理员窗口、不改系统）。

  ★ 只有"自动装"没成功时（比如网络把下载挡了、四个镜像都连不上），它才会打开
    这份文件，请你手动装一次。下面是手动步骤。

一、放心吗 —— 会不会装到病毒 / 会不会动我的系统？

  · 只从镜像站或 python.org 下**官方那一个文件**，下完先算 SHA256、再看数字签名，
    两样都和官方对不上就**不装**（宁可让你手动来）。
  · 装的时候用 /quiet，只装给当前用户（不装到系统目录、不弹 UAC、不建快捷方式）。
  · 想跳过自动装这一步（比如你要自己掌控）：
        set TMM_NO_AUTOPY=1
    然后双击程序即可（只对当前那个命令行窗口有效）。


二、手动装 Python（只在自动装失败时才需要）

  1. 打开 https://www.python.org/downloads/
  2. 点那个黄色的 Download Python 3.12.x 按钮（3.10 以上都行）
  3. 双击下载好的安装包
  4. ★ 安装第一屏，**务必勾上最下面那个「Add python.exe to PATH」**
     （不勾它会怎样：命令行里找不到 python，虽然本程序会自己去找，但别的工具会报错）
  5. 点 Install Now，等它跑完，点 Close

三、验证装好了

  按 Win + R，输入 cmd，回车。在黑窗口里粘贴这一行，回车：

      python --version

  看到 Python 3.12.x 这样的字样就成了。

  如果提示「不是内部或外部命令」，说明第 4 步那个勾没勾 —— 重新跑一遍安装包，
  选 Modify，把 Add to PATH 勾上。

四、回到本程序

  再双击一次 Tiger.M.M.bat 就行。

  （如果你的 Python 装在别处、或者上面都做了还是找不到，
    可以告诉程序它的位置：Win + R → cmd → 回车，然后粘贴

        set TMM_PY=C:\你的路径\python.exe

    再双击 Tiger.M.M.bat。）
