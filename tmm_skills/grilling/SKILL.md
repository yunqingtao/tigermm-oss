# grilling

一次一个逼决策的问题，把含糊想法问成一句话规格。关键在"**一次一个**"和"**答案会改变做法**"
这两条纪律：连发三问会让人挑最容易答的答，问空问题则等于没问。每个问题都给 2-3 个具体候选。

来源：本机版重写自 Meta Muse Code 的内置技能 `/grilling`。
