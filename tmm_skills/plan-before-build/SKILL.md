# plan-before-build

动手前把方案钉死：摸现场 → 只点关键决策 → 停在等你批准。为什么要有这条：方案里最容易错的
不是技术选型，而是**在没核实现场的情况下设计**，以及**顺手开始写**——后者让"先定做法"这件事
直接失效。所以本技能明令禁止开工，输出只有一份待批方案。

来源：本机版重写自 Meta Muse Code 的内置技能 `/plan`（内置 playbook 的形态被证明有用：
显式调用、只作用于当轮、结尾停下等批准）。Muse 那版是按它自己的项目文件写的，本机版换成
本机的工具体系与输出纪律（中文、短句、无空话）。
