03怎么用

三步：装依赖 → 填模型（或只装本地模型）→ 启动。

# 1. 安装（建目录 + 从模板生成 keys.json + 自检）
python install.py

# 2. 配模型 —— 编辑 keys.json 填一家的 Key
#    只想本地跑：装 Ollama 后 ollama pull qwen2.5:7b，不用填任何 Key

# 3. 启动
python main.py          # 命令行
python start_web_ui.py  # 网页版 → localhost:8800

# 4. 自检（一条命令跑全部门禁）
python scripts/hermes_verify.py
入口文件说明
命令行main.py终端交互
网页版start_web_ui.py浏览器界面，默认 8800
桌面窗口Tiger.M.M.bat原生窗口（pywebview）
数据面open_data_ui.bat产物 / 专家 / 审计（只读）
门禁verify.bat跑全部自检

04自检与质量

每次改动都必须跑门禁；改动即验证，没跑过的不算做完。

门禁 46 道

覆盖路由、链条、技能、办公生成、诚实失败、静默失败、权限护栏、分发就绪、个人数据边界、多模型路由矩阵等。

单元测试 917 条

pytest 全绿。与门禁互补：门禁盯"已知缺陷不许回退"，测试盯"函数行为"。

验证纪律

探针必须走隔离沙箱（TMM_PROBE），绝不写用户真实数据；验证器自己也要留档可复跑。

# 全部门禁（自动发现 scripts/verification/verify_*.py）
python scripts/hermes_verify.py

# 单跑某一道
python scripts/verification/verify_route_registry.py

05边界与诚实说明

拿过去能不能跑、缺什么会怎样 —— 先说清，不假装。

已知限制

  • 平台：仅 Windows（桌面自动化、win32 输入、系统语音都依赖 Win32）。
  • 模型：至少要有一家 —— 云端 Key（deepseek / mimo / qwen）或本地 Ollama。
  • 部分工具需自备服务：邮件（163 授权码）、短信（腾讯云）、推送（ntfy / Server酱）。没配会如实报"没配置"，不会假装成功。
  • 凭据位置：全部在 keys.json（不进 git）；模板见 keys_template.json。
  • 数据边界：对话史 / 备份 / 日志都在 data/ logs/ backups/，随包不携带个人数据。

它不会做的事

  • 不删系统文件、不改密码、不代做决定。
  • 办不成不会包装成办成了 —— 失败就说失败，缺什么就报什么。
  • 验证流量绝不写用户真实数据（硬闸 + 路径隔离双保险）。
